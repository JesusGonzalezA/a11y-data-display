# 1.1 Bienvenida y presentación

> Módulo 1 · Introducción · sin página de ejemplo

## Objetivo

- Presentar el curso, al docente y a quién va dirigido.
- Explicar qué significa presentar datos de forma accesible.
- Presentar las cuatro tareas que guían el curso y el formato de cada lección.

## Ideas clave

- Presentar datos de forma accesible = que cualquier persona pueda **comprender** un dato, **recorrer** una colección, **comparar** valores y **operar** sobre ellos.
- El significado no puede depender solo de la disposición visual: iconos, color, columnas o posición.
- La estructura (lista, tabla, encabezados) es lo que el navegador comunica a las tecnologías asistivas.
- Cada lección: lección → situación → error común → solución.
